Ejercicio 1: Variables y typeof

Declaración de variables de distintos tipos, uso de const y let, y comprobación con typeof.

Código ejecutado:
const edad = 20;
const nombreUsuario = "Achraf";
const esEstudiante = true;
const datoNulo = null;
let variableIndefinida;
const numeroGrande = 10n;
let ciudad = "Granada";

console.log(edad, typeof edad);
// ... (ver app.js para el resto)
Predicción y Resultados:
Variable / Expresión Valor TypeOf Espero TypeOf Sale

Nota sobre null: typeof null devuelve "object" debido a un error histórico en la primera implementación de JavaScript que se ha conservado por compatibilidad.

Ejercicio 3: Coerción y comparaciones

Evaluación de expresiones mixtas y comparaciones estrictas (===) frente a débiles (==).

Código ejecutado:
"5" - 2;
"5" + 2;
"10" * "2";
true + 1;
null + 5;
undefined + 1;
5 == '5'; 5 === '5';
0 == false; 0 === false;
null == undefined; null === undefined;
Tabla Expresión / Espero / Sale:
Expresión Espero Sale
"5" - 2 3 3
"5" + 2 "52" "52"
5 == '5' true true
5 === '5' false false
0 == false true true
0 === false false false
null == undefined true true
null === undefined false false

Explicación de coerción: Con el operador +, si uno de los operandos es una cadena, JavaScript prioriza la concatenación. En cambio, con operadores como - o *, fuerza la conversión numérica.

Ejercicio 4: Tu ficha con plantillas de cadena

Construcción de ficha personal utilizando plantillas de cadena, concatenación clásica y gestión de errores con const.

Código ejecutado:
const nombre = "Achraf";
let horasEstudio = 6;
horasEstudio += 4;
const msgTemplate = `Hola, me llamo ${nombre}...`;
const msgConcat = "Hola, me llamo " + nombre + "...";
console.log(msgTemplate === msgConcat); // true
Error al reasignar una const:
Uncaught TypeError: Assignment to constant variable.

Significado: Ocurre al intentar cambiar el valor de una constante ya inicializada. JavaScript bloquea la reasignación para proteger los datos fijos.
